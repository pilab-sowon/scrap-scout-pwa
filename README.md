# 줍줍값 PWA

사진을 기록하고 재질·무게·고물상 단가·운반비를 입력해 예상 매입가와 실수익 범위를 계산하는 설치형 모바일 웹앱입니다.

## 실행

```bash
npm test
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 같은 와이파이의 휴대폰에서 테스트하려면 실행 컴퓨터의 로컬 IP와 포트 `4173`으로 접속합니다. 카메라와 PWA 설치는 배포 환경에서 HTTPS가 필요할 수 있습니다.

## 범위

- 카메라 촬영/사진 선택 및 미리보기
- 재질별 샘플 단가 편집
- 분리 상태에 따른 회수율 반영
- 무게·운반비·최소 희망수익 기반 판정
- 최근 감정 기록(localStorage)
- Web Share API
- 오프라인 앱 셸(service worker)

사진 기반 재질 자동분류와 고물상 실시간 단가는 포함하지 않습니다. 결과는 사용자가 입력한 단가에 따른 참고용 추정치입니다.
